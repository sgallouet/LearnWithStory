# Japanese Book Library

A lightweight static book-selection app for Japanese learning stories.

Asset layout:

```text
assets/
  contextual-situation/
    ramen-quest/
      covers/
      pages/
        page-001/
          metadata.json
  nodeheart-series/
    nodeheart-luminus/
      covers/
      pages/
        page-001/
          metadata.json
```

Open `index.html` directly, or serve the folder with `python -m http.server`.
